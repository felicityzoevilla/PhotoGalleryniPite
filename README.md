# Photo Gallery ni Pite

A responsive photo gallery website that showcases my happiest moments in life. Each photo comes with a short description and a note on why that moment made me so happy. Built with **HTML, CSS, JavaScript and Bootstrap** as part of my Applications & Development Technologies Subject.

## Features

- **moments** a photo, year, description and the reason it matters
- **Responsive layout** that adapts from phones to large screens using the Bootstrap grid
- **Click-to-enlarge lightbox** built with the Bootstrap modal
- **Modern hover effects**: cards lift with a soft box shadow, photos zoom, and an accent bar slides in
- **Clean, bright design** with a custom color palette and readable typography
- **Accessible**: image alt text, visible keyboard focus, and reduced-motion support

## Built with
| Technology | Purpose |
| --- | --- |
| HTML | Page structure |
| CSS | Custom styling, shadows, hover animations |
| JavaScript | Generates the gallery cards and lightbox |
| Bootstrap | Grid, cards, navbar and modal |

## Project structure

```
photo-gallery/
├── index.html     # Page layout and Bootstrap components
├── style.css      # Custom design, shadows and hover effects
├── script.js      # Photo data and gallery rendering
└── images/        # Your photos
```

## What I learned

- Building a responsive layout with the Bootstrap grid system
- Using Bootstrap components such as the navbar, cards and modal
- Separating HTML, CSS and JavaScript into their own files
- Adding box shadows and hover transitions for a modern look
- Generating page content from data with JavaScript
